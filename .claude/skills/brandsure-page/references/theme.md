# The BSU theme — lane code, motion, components

Source: `theme-source/BSU_Master_Theme_Spec_v3.md` and `theme-source/theme.js`
(BSU Master Theme v3, 4 Sep 2026). Both are **inputs — never edit them.**

The spec is written for *video decks*. Layer 4 v4 §8 gives the only licence to
adapt it:

> Website adaptation: light surfaces with restrained navy callouts, consistent
> lane meanings. Translate slide typography into responsive web sizes rather
> than copying points into CSS.

So point sizes never become pixels and slide layout never becomes page layout.
What carries over one-to-one: the **lane code**, the **icon form**, the **four
components**, and the **motion grammar**.

---

## 1. The lane code — the theme's central idea

> Blue is us, green is you.

| Lane | Colour | Means |
|---|---|---|
| `bs` | `--bs-lane-bs` · blue `#116E98` | BrandSure does it — our work, our money |
| `you` | `--bs-lane-you` · green `#22BE6C` | You do it · a closed sale · money you keep · included |
| `shared` | `--bs-lane-shared` · teal `#30A4A0` | Shared · your team inside our journey |
| `problem` | `--bs-lane-problem` · slate `#4B6673` | A problem, a leak. **Never red.** Its consequence is a yellow pill |
| `quiet` | `--bs-lane-quiet` · mist `#F0F8F7` | Quiet, on a tinted panel; glyph is blue |

**Set `--bs-lane`; never name a colour.** `theme.js` derives an icon's colour
from its *meaning* (`ICON_LANE` → `CIRCLE`), which is what lets a reader follow
blue-versus-green without a legend. A component that picks blue itself breaks
that the moment somebody forgets.

This is also what makes the Lane Switch buildable: recolouring the whole chain
for a different plan is one variable, not a rewrite.

### Colours that are not lanes

- `#DCEBF0` (`--bs-mist-2`) — money belonging to nobody: GST, material,
  transport. Quiet, never coloured.
- Glow: aqua + warm yellow, very low opacity, **bottom-right only, never behind
  text**.

### Contrast, measured

| | On white | Use |
|---|---|---|
| `--bs-green` `#22BE6C` | ~2.4:1 | fills and glyphs only — **never small text** |
| `--bs-green-d` `#1BA85C` | passes | green text on light |
| `--bs-blue` `#116E98` | 4.9:1 | text and fills |

Three theme colours are overridden in `tokens.css` for AA — `SUB`, the yellow
text pairing, and the theme's own `WARN_TXT`, which is only 3.62:1 on the very
strip it was written for. Each override carries its measurement.

## 2. Icons

Theme §3: *"A Lucide glyph at 2px stroke, filling 50% of a solid circle, always
centred. The circle fill is the lane code — no borders, no tiles, no rounded
squares."*

Two forms, both generated by `npm run build:icons`:

- `#bs-icon-NAME` — bare glyph, inherits `currentColor`, for use beside text
- `#bs-circle-NAME` — the theme form: white glyph in a solid lane-coloured circle

35 meanings: the theme's 29 plus six the website needs (menu, close, arrow,
play, compass, grid). Never hand-draw a glyph — add the meaning to the theme
file and regenerate.

## 3. Motion — M1 to M6

Straight from theme §6. Durations are the theme's own, generated into
`tokens.css` as `--bs-m1-settle` … `--bs-m6-grow`.

| Move | Theme | Web | Applies to |
|---|---|---|---|
| **M1 SETTLE** | Float In from bottom 0.4s | opacity + `translateY(14px→0)` | headlines, subs, labels, rows, the dark payoff card |
| **M2 DRAW** | Wipe from left 0.5s | `clip-path: inset()` or `scaleX` from `transform-origin: left` | tick bar, split bars, rulers, chevrons, meters, the aqua spine |
| **M3 POP** | Zoom from centre 0.3s | `scale(0.9→1)` + opacity | icon circles — **only** circles |
| **M4 VERIFY** | Zoom 0.25s → Pulse ×1 | scale, then one `scale(1→1.06→1)` | green ticks, pills, badges, RECOMMENDED — **always last** |
| **M5 FLOW** | M3 per node, 0.15s stagger | `transition-delay` ladder | chains, lane rows, funnels |
| **M6 GROW** | Wipe from bottom 0.6s → number M1 | `scaleY` from bottom, then the number settles | stat rows, stacks, bars |

### The firing order is fixed

> tick bar (M2) → headline (M1) → sub (M1) → picture → dark card → green
> accents (M4)

**The green beat lands last, every time.** That single rule is most of what
makes the decks read as composed rather than busy, and it does the same here.

Page transitions: Fade 0.5s (`--bs-page-fade`), Push From Bottom 0.6s into the
gate (`--bs-page-gate`) — the View Transitions API, no JavaScript.

**Nothing exits.** No bounce, spin, swivel or sound. Emphasis is reserved for M4.

### The gate that makes motion safe

Every animated "before" state lives under `.bs-motion`, a class the script adds
to `<html>`. Script blocked, slow or broken → the finished page. Write it the
other way round and a visitor without JavaScript gets a page of invisible
sections.

**Reveal by scroll sweep, not IntersectionObserver.** An observer reports
intersection *changes*; jump from the top of a page to the bottom in one frame
and every section in between goes from below the viewport to above it without
ever intersecting. No callback, no reveal, opacity nailed at 0 — this left 11
of 12 home-page sections permanently blank. A sweep asks whether the element's
top has passed the bottom of the viewport, which is true however the reader got
there.

## 4. Per-page tempo

Theme §6 gives each video a tempo. The pages inherit them, which is what stops
the site feeling uniformly animated.

| Page | Video | Tempo | Signature |
|---|---|---|---|
| **Home** | 1 Hook | fastest, 0.12s stagger | slate problem circles pop, then each yellow SALE LOST pill glows (M4) |
| **Plans** | 2 Choose | medium | the gauge draws, three owner circles pop left→right, MOST START HERE is the M4 beat |
| **Digital Partner** | 3 DP | clock-like | 9:04 → Saturday: circles pop in clock order down the aqua spine; the green "walks in ready" circle is last |
| **How It Works** | 5 How we work | orderly | lane cards: blue header band wipes, rows cascade, then the green card does the same |
| **Growth Partnership** | — | slowest | Video 4's tempo without its content. Restraint reads as seriousness |
| **Proof, About, Services, blog** | — | Home's grammar, quieter | no new moves — a page with a move nobody else uses looks like a different site |

## 5. The four components

Everything in the deck reduces to these.

- **C-Chain** — filled rounded step blocks, numbered white circle top-left,
  aqua chevron between. Block colour = whose step it is. Legend below.
- **C-LaneCards** — a coloured header band (blue for us, green for you) with a
  pill on the right, over a white body of icon-circle rows. Green card's border
  `#BEE9CF`, blue card's `#CFE4EA`.
- **C-StatRow** — 3–5 white chip cards on a mist panel. Blue number, subtle
  label, no icons. For the figures owners screenshot.
- **C-SplitBar** — **private.** It is the ₹33,000 breakdown: Video 4, Growth
  Partnership. Build it for the private funnel; never for brandsure.in.

## 6. Surfaces

- **The page is white.** The dark navy card is a *component* — at most one per
  page, where the payoff goes. There are no dark pages.
- Cards: white, radius 12px, 1px `#E8F3F2`, shadow `0 5px 9px rgba(17,110,152,.07)`.
- Dark payoff card: `#081E2E`, radius 12, no border, green circle icon at the
  top, white bold statement, muted tick lines.
- Disclaimer strip: `#FBF3DF` fill, `#FFEDC2` border, centred italic.
  **Every caveat lives here** — no inline disclaimers.
- Headlines: **tick bar** (a blue bar left of the headline) is the default.
  Pattern B (blue caps eyebrow + one blue phrase) is for section openers only.
  One per headline — **never colour a word in a tick-bar headline.**
